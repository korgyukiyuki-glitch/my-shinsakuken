GUIDE — 口腔機能低下症

口腔機能低下症とは──7項目の検査・診断基準・使う機器（令和8年度対応）

監修：歯科医師 和泉龍之介（Medical Craft Lab） 公開日 2026年10月21日 最終更新日 2026年10月21日

口腔機能低下症は、7つの下位症状のうち3項目以上に該当した場合に診断されます。この記事では、日本歯科医学会「口腔機能低下症に関する基本的な考え方」（令和8年3月。以下「基本的な考え方」）に沿って、7項目それぞれの検査方法・基準値・使う機器を一覧にまとめ、診断基準、傷病名の使い分け、管理計画書の項目までを整理します。

保険算定（管理料1・2、検査の点数、実地指導料）は、別記事「口腔機能低下症の算定（令和8年度）」で解説しています。

POINTS — この記事の要点

  • 診断基準は、7項目のうち3項目以上の該当
  • 主な基準値：舌圧 30kPa未満／オーラルディアドコキネシス 6回/秒未満／口腔粘膜湿潤度 27.0未満／咀嚼能力 100mg/dL未満
  • 令和8年3月版では、専用機器を使わない検査だけでも、3項目以上の該当で診断できることが明記された
  • 再評価は管理計画に従い概ね6か月ごと。保険の各精密検査は、管理中は3月に1回

口腔機能低下症とは

「基本的な考え方」では、口腔機能低下症を、加齢だけでなく疾患や障害などさまざまな要因によって、口腔の機能が複合的に低下している疾患としています。う蝕や歯の喪失のような器質的な障害とは異なり、いくつもの機能の低下が重なって現れる病態です。

放置すると、咀嚼障害や摂食嚥下障害などの機能障害に進み、低栄養やフレイル、サルコペニアを進めて全身の健康を損なうとされています。そのため、中年期からの適切な診断と管理が必要とされています。症状としては、口腔内の微生物の増加、口腔乾燥、咬合力の低下、舌や口唇の運動機能の低下、舌の筋力の低下、咀嚼や嚥下の機能の低下が挙げられています。

7項目それぞれの検査方法

以下は「基本的な考え方」の手順の要約です。舌口唇運動機能・舌圧・咀嚼機能の検査と咬合力検査は、義歯を使っている人は義歯を装着した状態で測ります。

① 口腔衛生状態不良：舌背上の微生物数／TCI

微生物数は、水に浸した滅菌綿棒を定圧検体採取器具に付け、20gfの力で舌背中央部を1cmの長さで3往復こすって検体を採り、口腔内細菌カウンタで測ります。TCI（Tongue Coating Index）は、舌の表面を9つに分け、各エリアの舌苔をスコア0・1・2の3段階で評価し、合計から算出します。

② 口腔乾燥：口腔粘膜湿潤度／唾液量

口腔粘膜湿潤度は、舌尖から約10mmの舌背中央部で測ります。唾液量はサクソンテストで、医療用ガーゼ（タイプⅢ・7.5cm四方・12Ply）の2分後の重量増加で評価します。

③ 咬合力低下：咬合力検査／残存歯数

咬合力検査は、咬頭嵌合位で3秒間くいしばったときの歯列全体の咬合力を測ります。基準値は使う機器と解析の条件で異なり、デンタルプレスケールⅡでは、バイトフォースアナライザの圧力フィルタによる自動クリーニングの有無で350N未満と500N未満に分かれます。両方を調べた場合は、咬合力検査の結果を優先します。

④ 舌口唇運動機能低下：オーラルディアドコキネシス

/pa/、/ta/、/ka/ をそれぞれ5秒間発音してもらい、回数を数えて1秒あたりに換算します。いずれか1つでも6回/秒未満なら該当です。

⑤ 低舌圧：舌圧検査

舌圧測定器につないだ舌圧プローブを、舌と口蓋の間で、随意的に最大の力で数秒間押しつぶしてもらい、最大舌圧を測ります。基準は30kPa未満で、「基本的な考え方」では年齢による区別は示されていません。

⑥ 咀嚼機能低下：咀嚼能力検査／咀嚼能率スコア法

咀嚼能力検査は、2gのグミゼリーを20秒間自由に咀嚼してもらい、10mLの水で含嗽させてからグミと水をメッシュ内に吐き出してもらい、通過した液のグルコース濃度を測ります。咀嚼能率スコア法は、専用のグミゼリーを30回咀嚼した後の粉砕の程度を、視覚資料と照らして評価します。どちらもグミゼリーを使うため、誤嚥・誤飲のリスクを考えて実施を判断します。

⑦ 嚥下機能低下：EAT-10／聖隷式嚥下質問紙

どちらかの質問紙で評価します。この項目の該当者には嚥下障害の患者が含まれるため、該当した場合は、反復唾液嚥下テスト、改訂水飲みテスト、頸部聴診法などのスクリーニングの結果も踏まえ、必要に応じて嚥下造影検査や嚥下内視鏡検査などの精密検査を行います。

口腔機能低下症の診断基準：7項目中3項目以上

7つの下位症状のうち3項目以上に該当する場合に、口腔機能低下症と診断されます。検査の実施については、「基本的な考え方」に次の整理があります。

  • 原則として、7項目すべての検査を行うことが望ましい
  • 実施できない項目がある場合は、実施した検査のうち3項目以上の該当で診断する
  • 専用機器が必要な検査（舌背上の微生物数・口腔粘膜湿潤度・咬合力検査・舌圧検査・咀嚼能力検査）をいずれも行わない場合でも、機器を用いない検査（TCI・サクソンテスト・残存歯数・オーラルディアドコキネシス・咀嚼能率スコア法・EAT-10または聖隷式）のうち3項目以上で診断する（令和8年3月版で明記）

検査結果は、診療録に記載するか、記録用紙（別添2）に記載して診療録に添付します。管理計画書（別添3）などに検査結果を記載し、その写しを添付する方法も示されています。なお、精密検査・診断・再評価は対面で行う必要があります。

専用機器を使う5つの検査を行ったかどうかで、算定できる口腔機能管理料の区分（管理料1・2）が変わります。詳しくは「口腔機能低下症の算定（令和8年度）」をご覧ください。

傷病名の3段階：疑い／口腔機能管理中／口腔機能低下症

検査の前後で使う傷病名は、次の3つに整理できます。

段階傷病名根拠
診断前（低下が疑われ、診断のために検査する）口腔機能低下症の疑い各精密検査の通知「加齢等による口腔機能の低下が疑われる患者に対し、口腔機能低下症の診断を目的として実施した場合に算定」（例：D012 舌圧検査 通知(2)イ）
検査の結果、3項目に届かないが管理が必要口腔機能管理中厚生労働省「疑義解釈資料（その1）」令和6年3月28日 歯科 問19
3項目以上に該当口腔機能低下症「基本的な考え方」の診断基準

令和6年の問19は、当時の歯科衛生実地指導料の口腔機能指導加算について、病名が口腔機能低下症などの場合に限るかを問うたものです。回答は次のとおりです。

検査の結果、口腔機能発達不全症又は口腔機能低下症の確定診断には至らなかったが、口腔機能管理の必要性があり口腔機能管理を実施する場合は当該加算を算定可能である。この場合の傷病名は、「口腔機能管理中」として差し支えない。
（疑義解釈資料の送付について（その1）令和6年3月28日 事務連絡 歯科 問19）

使うときは、次の3点に注意してください。

  • 問19は、該当項目の数による線引きを定めていません。「1〜2項目の該当で口腔機能管理中」とする整理は運用上のもので、管理が必要かどうかは歯科医師が判断します。
  • 令和8年度改定で口腔機能指導加算は削除され、口腔機能実地指導料が新設されました。改定後の扱いは、地域の審査の考え方も含めて確認してください。
  • 口腔機能管理料は「口腔機能低下症の患者」が対象です（告示 B000-4-3 注1）。口腔機能管理中の患者は、口腔機能管理料の対象になりません。

口腔機能低下症の管理計画書の項目と再評価の時期

初回には、管理計画書（「基本的な考え方」別添3）を参考に管理計画を作り、口腔機能の問題と管理計画を患者に説明します。別添3の管理計画書は、次の5つの欄で構成されています。

欄記載する内容
全身の状態基礎疾患、服用薬剤、肺炎の既往、栄養状態（体重・身長・BMI）、体重の変化、食事形態、食欲
口腔機能の状態7項目の検査結果と基準値（オーラルディアドコキネシスはパ・タ・カ別、舌の力は舌圧）、歯・歯肉の状態、口腔内・義歯の状態
口腔機能管理計画口腔内の衛生・乾燥・咬む力・口唇の動き・舌尖の動き・奥舌の動き・舌の力・咀嚼・嚥下の9項目を、「問題なし／機能維持を目指す／機能向上を目指す」から選ぶ
管理方針・目標・治療予定管理の方針、目標（ゴール）、治療予定など
再評価の時期・治療期間再評価の時期（約○か月後）

出典：「基本的な考え方」（令和8年3月）別添3「管理計画書」。

再評価は、管理計画に従って概ね6か月ごとに口腔機能精密検査で行い、そのたびに管理計画書を作成・交付します。再評価で該当項目が2項目以下になった場合は回復（治癒）と考えられますが、管理をやめると再び低下するおそれがあると総合的に判断される場合は、患者の同意を得て管理を続けます。

また、咬合力・舌圧・咀嚼能力の維持向上のために管理している患者には、訓練の効果の確認や動機づけのため、必要に応じて3か月ごとに検査を行うことが示されています。保険で算定する各精密検査も、管理中は3月に1回に限り算定できます。

「基本的な考え方」令和8年3月版で変わった主な点

令和8年度の点数表の通知（B000-4-3 口腔機能管理料 通知(1)）では、管理にあたって令和8年3月版の「基本的な考え方」を参考にするよう示されています。令和6年3月版と比べた主な違いは次のとおりです。

  • 7項目の該当基準の数値は変わっていません。
  • 咬合力検査：375N未満の対象機器に、Oramo2 のUセンサー（bf-センサーシート Uタイプ）が加わった
  • 診断：「口腔機能精密検査の実施と診断」の項目が設けられ、専用機器を使わない検査だけでも3項目以上で診断できることが明記された
  • 全身状態の把握：評価項目に身体機能と栄養状態が加わり、GLIM基準、AWGS 2025基準、下腿周囲長なども参考になるとされた

口腔機能低下症の検査についてよくある質問

舌圧の基準値は年齢によって変わりますか？

変わりません。「基本的な考え方」では、年齢を区別せず、舌圧30kPa未満を低舌圧としています。本文・記録用紙・管理計画書のいずれも同じ基準です。

7項目すべての検査をしないと診断できませんか？

原則として7項目すべての検査を行うことが望ましいとされていますが、実施できない項目がある場合は、実施した検査のうち3項目以上の該当で診断します。令和8年3月版では、専用機器を使わない検査だけでも3項目以上該当すれば診断できることが明記されました。

咬合力検査と残存歯数の両方を調べた場合、どちらを使いますか？

咬合力検査の結果を優先します。残存歯数は、残根と動揺度3の歯を除いて数えます。

再評価はどのくらいの間隔で行いますか？

「基本的な考え方」では、管理計画に従って概ね6か月ごとに口腔機能精密検査で再評価するとされています。保険で算定する各精密検査は、口腔機能低下症の管理中は3月に1回に限り算定できます。

記録と管理計画書の作成をアプリで

「口腔機能管理くん」は、歯科医院向けの口腔機能管理アプリです。7項目の検査値を入力すると、この記事で紹介した日本歯科医学会の基準値に照らして該当項目を集計し、レーダーチャートで表示します。検査結果から管理計画書をPDFで作成でき、前回の検査から期間がたった患者さんはホーム画面に一覧で表示されます。

iPhone・iPad・Android 対応／月額1,000円・年額9,800円（税込）、すべてのプランに1か月の無料トライアル。※ 記録と書類作成を支援するアプリで、医療機器ではありません。診断は歯科医師が行います。
