GUIDE — 口腔機能管理

口腔機能管理とは──口腔機能低下症・口腔機能発達不全症・周術期等口腔機能管理の違い（令和8年度）

監修：歯科医師 和泉龍之介（Medical Craft Lab） 公開日 2026年10月23日 最終更新日 2026年10月23日

歯科の保険診療で「口腔機能管理」という言葉が出てくる場面は、主に3つあります。高齢の患者さんの口腔機能低下症、小児の口腔機能発達不全症、そして、がん等の手術や放射線治療を受ける患者さんの周術期等口腔機能管理です。対象も、診断の根拠も、管理料の名前も点数も、それぞれ違います。

この記事では、令和8年度診療報酬改定（2026年6月施行）の告示・通知の原文をもとに、3つの「口腔機能管理」の違いを1ページで整理します。各疾患の検査方法や算定の細かい組み立ては、末尾の関連ガイドで解説しています。

POINTS — この記事の要点

  • 口腔機能低下症＝口腔機能管理料（B000-4-3）。7項目中3項目以上で診断。管理料1 90点／2 50点、月1回
  • 口腔機能発達不全症＝小児口腔機能管理料（B000-4-2）。18歳未満。C項目2つ以上で診断。管理料1 90点／2 50点、月1回
  • 周術期等口腔機能管理＝計画策定料（B000-5）300点と管理料（Ⅰ）〜（Ⅳ）（B000-6〜9）。がん等の手術・放射線治療・化学療法・集中治療室での治療・緩和ケアの患者が対象。手術等を行う医療機関からの依頼文書が起点（同じ医療機関で手術等を行う場合は依頼文書は不要）
  • 3つは同じ月に併算定できない（例外あり）。歯科衛生士の指導・処置の項目も、低下症・発達不全症は口腔機能実地指導料、周術期等は周術期等専門的口腔衛生処置、と分かれる

「口腔機能管理」が指す3つのもの

歯科点数表の「第2章 特掲診療料 第1部 医学管理等」には、口腔機能の管理を評価する項目が並んでいます。名前が似ているので、まず区分番号と対象で切り分けます。

  • 口腔機能管理料（B000-4-3）：口腔機能低下症の患者に対する管理。通知(1)は対象を「50歳以上の歯の喪失や加齢、これら以外の全身的な疾患等による口腔機能低下症の患者」とし、関係学会の診断基準で診断された患者に、管理計画に基づく継続的な管理を行った場合に算定します。
  • 小児口腔機能管理料（B000-4-2）：口腔機能発達不全症の18歳未満の患者に対する管理。正常な口腔機能の獲得を目的とし、関係学会の診断基準で診断された患者に、管理計画に基づく継続的な管理を行った場合に算定します（注1・通知(1)）。
  • 周術期等口腔機能管理計画策定料（B000-5）と周術期等口腔機能管理料（Ⅰ）〜（Ⅳ）（B000-6〜B000-9）：がん等に係る手術、放射線治療、化学療法、集中治療室における治療、緩和ケアを受ける患者の口腔機能を管理するものです。疾患名ではなく、主病の治療に伴う管理で、手術等を実施する医療機関からの文書による依頼が起点になります（B000-5 注1）。

このほかに、療養病棟・回復期リハビリテーション病棟・地域包括ケア病棟に入院中の患者を対象とする回復期等口腔機能管理（B000-10 計画策定料、B000-11 管理料）があります。周術期等と同じ構造（計画策定料1 300点・2 150点）ですが、この記事では扱いません。

口腔機能低下症の管理（口腔機能管理料）

口腔機能低下症は、口腔衛生状態不良、口腔乾燥、咬合力低下、舌口唇運動機能低下、低舌圧、咀嚼機能低下、嚥下機能低下の7項目のうち、3項目以上に該当した場合に診断します。診断の前に「口腔機能低下症の疑い」で検査を行い、診断後は管理計画を作成して、歯科疾患管理料（90点）と口腔機能管理料（月1回）で継続管理します。

口腔機能管理料1（90点）と2（50点）を分けるのは、専用機器を使う指定の5つの検査（口腔細菌定量検査2・咀嚼能力検査1・咬合圧検査1・口腔粘膜湿潤度検査・舌圧検査）のいずれかを実施した患者かどうかです（注2・注3）。TCI・サクソンテスト・オーラルディアドコキネシス・EAT-10 など、機器を使わない検査だけで診断した患者は管理料2の対象です。

  • 7項目の検査方法・基準値・使う機器 → 口腔機能低下症とは──7項目の検査・診断基準・使う機器
  • 管理料1・2の算定要件、検査の頻度、実地指導料の施設基準 → 口腔機能低下症の算定（令和8年度）

口腔機能発達不全症の管理（小児口腔機能管理料）

口腔機能発達不全症は、チェックリスト（離乳完了前は別紙1、離乳完了後は別紙2）の「食べる機能」「話す機能」のC項目で2つ以上に該当し、かつ離乳完了前はC-1〜C-9、離乳完了後はC-1〜C-6のいずれかを含む場合に診断します。小児口腔機能管理料の対象は、口腔機能発達不全症の18歳未満の患者です（注1）。

管理料1（90点）と2（50点）を分けるのは、口腔機能の評価項目に該当する数です。3項目以上が管理料1、2項目が管理料2で、検査の実施で分ける口腔機能低下症とは考え方が違います（注2・注3）。また、初回算定日には口腔外または口腔内のカラー写真の撮影が必要で、その後も管理料3回の算定に1回以上撮影します（通知(3)）。

  • 2種類のチェックリストのC項目と評価基準、口唇閉鎖力・舌圧の年齢別基準値 → 口腔機能発達不全症のチェックリスト（離乳完了前・離乳完了後）とC項目の見方
  • 「評価項目」の数え方、写真撮影の要件、検査の頻度 → 口腔機能発達不全症の算定（令和8年度）

周術期等口腔機能管理（計画策定料と管理料（Ⅰ）〜（Ⅳ））

周術期等口腔機能管理は、がん等に係る手術（歯科疾患に係る手術は入院期間が2日を超えるものに限る）、放射線治療、化学療法、集中治療室における治療、緩和ケアを受ける患者の口腔機能を管理するものです。口腔内細菌による手術部位感染や病巣感染、気管内挿管による誤嚥性肺炎などの術後合併症、術後の栄養障害の予防などを目的にしています（B000-6・B000-7 通知(1)）。放射線治療や化学療法の副作用として生じた口腔粘膜炎に対する処置は、周術期等専門的口腔衛生処置2で評価されます（I029 通知(3)）。

算定の流れ

  1. 依頼：手術等を実施する医療機関から、文書による依頼を受けます。歯科診療を実施している医療機関が自院で手術等を行う場合、依頼文書は要りません（B000-5 通知(2)）。
  2. 計画の策定：患者等の同意を得て、周術期等の口腔機能の評価と一連の管理計画を策定し、管理計画書を文書で提供します。周術期等口腔機能管理計画策定料1（300点）を、一連の治療を通じて1回算定します（注1）。患者の状態の変化等で治療計画を変更した場合は、策定料2（150点）を患者1人につき1回算定できます（注2）。
  3. 管理：管理計画書に基づいて歯科医師が口腔機能の管理を行い、管理報告書（口腔内の状態の評価、実施内容・指導内容など）を患者に提供します。患者の状況に応じて、管理料（Ⅰ）〜（Ⅳ）を算定します。
  4. 歯科衛生士の処置：管理を行う歯科医師の指示を受けた歯科衛生士が専門的口腔清掃を行った場合は、周術期等専門的口腔衛生処置1（100点）を算定します（I029 注1・注2）。

歯科診療所が関わるのは、主に（Ⅰ）と（Ⅲ）です。たとえば、病院でがんの手術を受ける予定の患者さんを、依頼文書に基づいて外来で管理する場合は（Ⅰ）、外来で化学療法を受けている患者さんを管理する場合は（Ⅲ）になります。歯科診療所の歯科医師が医科歯科併設の病院に入院中の患者に歯科訪問診療を行って管理する場合も（Ⅰ）で算定します（通知(6)）。手術の前後に放射線治療や化学療法を行う場合は、（Ⅰ）または（Ⅱ）と、（Ⅲ）または（Ⅳ）を同一月に算定して差し支えありません（B000-8・B000-9 通知(5)）。

周術期等の管理では、歯科疾患管理料は前提になりません。むしろ、周術期等口腔機能管理料を算定した月は歯科疾患管理料を算定できず、算定した日の属する月の翌月以降から、管理計画を作成して患者等に説明したうえで歯科疾患管理料を算定できます（B000-4 通知(7)）。

同月の併算定と、歯科疾患管理料との関係

3つの「口腔機能管理」は、それぞれの告示の注で、同じ月の併算定が制限されています。

  • 口腔機能管理料・小児口腔機能管理料を算定した月：周術期等口腔機能管理料（Ⅰ）〜（Ⅳ）、回復期等口腔機能管理料、歯科疾患在宅療養管理料、在宅患者（小児在宅患者）訪問口腔リハビリテーション指導管理料、歯科矯正管理料は算定できません（B000-4-2・B000-4-3 注6）。
  • 周術期等口腔機能管理料を算定した月：歯科疾患管理料、小児口腔機能管理料、口腔機能管理料、回復期等口腔機能管理料、歯科特定疾患療養管理料、歯科治療時医療管理料、歯科疾患在宅療養管理料、歯科矯正管理料などは算定できません（B000-6〜B000-9 の注）。ただし、同月であっても、手術前にこれらの管理料を算定し、手術後に口腔機能管理を行う場合は、周術期等口腔機能管理料（Ⅰ）（Ⅱ）を算定できます（B000-6・B000-7 通知(8)）。
  • 口腔機能管理料と小児口腔機能管理料：対象がそれぞれ口腔機能低下症の患者、口腔機能発達不全症の18歳未満の患者なので、同じ患者に同時に当てはまる場面は想定しにくい組み合わせです。

歯科疾患管理料（90点）との関係も、3つで違います。口腔機能低下症と口腔機能発達不全症の管理料は、歯科疾患管理料（または歯科特定疾患療養管理料）を算定した患者が対象で、管理計画には口腔機能の検査結果を踏まえた治療方針を含めます（B000-4 通知(5)）。周術期等では、上記のとおり歯科疾患管理料は同月に算定できず、翌月以降に切り替えます。

歯科衛生士の項目も分かれています。口腔機能実地指導料（46点）の対象は「口腔機能の発達不全を有する患者又は口腔機能の低下を来している患者」で、施設基準の届出が必要です（B001-2-2 注）。周術期等の患者には、周術期等専門的口腔衛生処置（I029）を使います。

どの「口腔機能管理」に当てはまるかの見分け方

  1. 手術等を行う医療機関からの依頼（同じ医療機関なら依頼文書は不要）があり、がん等の手術・放射線治療・化学療法・集中治療室での治療・緩和ケアの患者か → 周術期等口腔機能管理。計画策定料を算定し、入院の有無と治療の種類で（Ⅰ）〜（Ⅳ）を選ぶ。
  2. それ以外で、18歳未満の患者か → 口腔機能発達不全症を疑い、チェックリストで評価。C項目2つ以上（必須の項目を含む）で診断し、小児口腔機能管理料1・2。
  3. それ以外で、歯の喪失や加齢、全身的な疾患等による口腔機能の低下が疑われる患者か → 口腔機能低下症を疑い、7項目を検査。3項目以上で診断し、口腔機能管理料1・2。
  4. 検査やチェックリストで該当があるものの、診断基準に届かない場合 → 「口腔機能管理中」として経過を追う。管理料の対象にはならない（低下症の傷病名の3段階・発達不全症の傷病名の3段階）。

周術期等の患者さんが、同時に口腔機能低下症の診断基準を満たすこともあります。その場合も、原則として同じ月に両方の管理料は算定できません（注6。手術前に口腔機能管理料等を算定した月の手術後の（Ⅰ）（Ⅱ）など、通知(8)の例外があります）。どちらで管理するかは、主病の治療の段階と、患者さんにとって優先すべき管理の内容で判断し、月をまたいで切り替えるときは、管理計画書を作り直して説明します。

口腔機能管理の違いについてよくある質問

「口腔機能管理料」と「口腔機能管理」は同じ意味ですか？

違います。「口腔機能管理料」は、口腔機能低下症の患者を管理したときに算定する B000-4-3 の名称です。「口腔機能管理」は、口腔機能低下症、口腔機能発達不全症、周術期等の3つの場面に共通して使われる言葉で、発達不全症は小児口腔機能管理料（B000-4-2）、周術期等は周術期等口腔機能管理料（Ⅰ）〜（Ⅳ）（B000-6〜B000-9）で評価されます。

口腔機能低下症と口腔機能発達不全症は、年齢で分かれますか？

小児口腔機能管理料の対象は、口腔機能発達不全症の18歳未満の患者です（B000-4-2 注1）。口腔機能管理料の通知(1)は、対象を「50歳以上の歯の喪失や加齢、これら以外の全身的な疾患等による口腔機能低下症の患者」と書いています。18歳以上50歳未満の患者を口腔機能低下症として管理する場合の扱いは、通知の文言だけでは一律に決められないため、地域の審査の考え方を確認してください。

周術期等口腔機能管理は、歯科診療所でも算定できますか？

できます。周術期等口腔機能管理料（Ⅰ）（手術前280点・手術後190点）と（Ⅲ）（200点）は、歯科診療を実施している保険医療機関が、（Ⅰ）は入院中でない患者または手術を行う他の病院に入院中の患者を、（Ⅲ）は入院中でない患者を管理した場合に算定します（他の病院に入院中の放射線治療等の患者は（Ⅳ）です）。手術等を実施する医療機関からの文書による依頼に基づいて、周術期等口腔機能管理計画策定料（300点）を算定し、管理計画書を作成することが前提です（B000-5 注1、B000-6 注1、B000-8 注1）。

同じ月に、口腔機能管理料と周術期等口腔機能管理料を両方算定できますか？

原則としてできません。口腔機能管理料・小児口腔機能管理料を算定した月は周術期等口腔機能管理料（Ⅰ）〜（Ⅳ）を算定できず（B000-4-2・B000-4-3 注6）、周術期等口腔機能管理料を算定した月は歯科疾患管理料・小児口腔機能管理料・口腔機能管理料などを算定できません（B000-6〜B000-9 の注）。ただし、同月であっても、手術前にこれらの管理料を算定し、手術後に口腔機能管理を行う場合は、周術期等口腔機能管理料（Ⅰ）（Ⅱ）を算定できます（B000-6・B000-7 通知(8)）。

口腔機能実地指導料は、3つのどの口腔機能管理で算定できますか？

口腔機能実地指導料（46点）の対象は、口腔機能の発達不全を有する患者または口腔機能の低下を来している患者です（B001-2-2 注）。周術期等の患者に対する歯科衛生士の処置は、周術期等専門的口腔衛生処置1（100点）・2（110点）（I029）で評価されます。

管理料1と2の分け方は、口腔機能低下症と口腔機能発達不全症で同じですか？

違います。口腔機能管理料（低下症）は、指定の5つの検査（口腔細菌定量検査2・咀嚼能力検査1・咬合圧検査1・口腔粘膜湿潤度検査・舌圧検査）のいずれかを実施した患者が1（90点）、それ以外が2（50点）です。小児口腔機能管理料（発達不全症）は、口腔機能の評価項目で3項目以上に該当する患者が1（90点）、2項目に該当する患者が2（50点）です。周術期等口腔機能管理料には、検査の実施や該当項目の数で分ける1・2の区分はなく（（Ⅰ）（Ⅱ）の「1 手術前」「2 手術後」は時期の区分です）、（Ⅰ）〜（Ⅳ）は患者が入院中かどうかと、手術か放射線治療等かで分かれます。

口腔機能低下症と発達不全症の記録・管理計画書をアプリで

「口腔機能管理くん」は、歯科医院向けの口腔機能管理アプリです。口腔機能低下症の7項目の検査結果と、口腔機能発達不全症のチェックリストの該当項目を記録すると、学会の基準値に照らして該当項目を集計し、評価の結果に応じて関係する保険算定項目と点数の目安をアプリ内に表示します。歯周検査・咬筋検査の記録にも対応し、管理計画書と紹介状はPDFで作成できます。

iPhone・iPad・Android 対応／月額1,000円・年額9,800円（税込）、すべてのプランに1か月の無料トライアル。※ 記録と書類作成を支援するアプリで、医療機器ではありません。診断は歯科医師が行い、算定の可否は各医院でご確認ください。周術期等口腔機能管理の書類作成には対応していません。
