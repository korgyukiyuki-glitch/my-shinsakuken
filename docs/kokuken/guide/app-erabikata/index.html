GUIDE — アプリの選び方

口腔機能管理アプリの選び方──口腔機能低下症・発達不全症の記録と管理計画書で確かめたい10のこと

執筆・監修：歯科医師 和泉龍之介（Medical Craft Lab） 公開日 2026年10月23日 最終更新日 2026年10月23日

口腔機能低下症や口腔機能発達不全症の検査結果を記録し、管理計画書を作る作業に、アプリを使う歯科医院が増えています。ただ、機能の一覧を眺めるだけでは、自分の医院の患者層や運用に合うかは判断しにくいものです。

この記事では、導入前に確かめたい10のことを、「なぜ大事か（制度・運用の根拠）」と「確かめ方（デモや無料期間で何を試すか）」に分けて整理します。特定の製品を比べる記事ではありません。制度の根拠は、令和8年度の告示・通知と、日本歯科医学会の「基本的な考え方」によります。最後に、当社のアプリ「口腔機能管理くん」がこの10項目にどう当てはまるかを、事実だけ表にまとめました。

POINTS — この記事の要点

  • 最初に決めるのは医院の対象患者。低下症の7項目、発達不全症の別紙1・別紙2、周術期等のどれが必要かで、見るべき範囲が決まる
  • 管理料の通知は、管理計画の情報を文書で提供し、写しを診療録に添付することを求めている。PDFで出せて、医院の診療録の運用に乗るかが要
  • 再評価の目安（低下症は概ね6か月ごと・学会）と写真撮影の要件（発達不全症は初回と管理料3回に1回以上・通知）の時期を把握できる仕組みがあるか
  • 料金は端末数・スタッフ数でどう変わるか、データはどこに保存され、解約後に持ち出せるかを、無料期間のうちに実際に試す

この記事の使い方

10項目は、制度に関わるもの（1〜3・5・9）と、医院の運用に関わるもの（4・6〜8・10）に分かれます。制度に関わる項目のうち、通知が定める算定要件（管理計画の文書提供と写しの添付、発達不全症の写真撮影など）は、合わなければ算定や記録に影響します。学会の「基本的な考え方」が示す目安（再評価の時期など）は、管理の質に関わるもので、算定要件そのものとは区別して読んでください。運用に関わる項目は、合わなくても使えますが、続かなくなる原因になります。デモや無料期間で確かめるときは、担当するスタッフが実際の患者さん1〜2人分を入力してみるのが近道です。

1. 対応する管理の範囲

CHECK 01医院の対象患者に合う範囲か

なぜ大事か歯科の「口腔機能管理」には、口腔機能低下症（口腔機能管理料・7項目の検査）、口腔機能発達不全症（小児口腔機能管理料・18歳未満・チェックリストは離乳完了前の別紙1と離乳完了後の別紙2）、周術期等口腔機能管理の3つがあり、対象も検査も書類も違います。高齢の患者さんが中心の医院と、小児が中心の医院では、必要な範囲が違います。歯周検査や咬筋の記録など、口腔機能以外の記録も同じアプリにまとめたいかどうかも、ここで決まります。

確かめ方医院で管理している（これから管理したい）患者さんを、低下症・発達不全症（離乳完了前／完了後）・周術期等に分けて数えます。その上で、必要な範囲の検査項目がすべて入力できるかを、デモで1人分入れて確かめます。3つの違いは「口腔機能管理とは」で整理しています。

2. 学会の最新の基準・様式への追随

CHECK 02基準値と項目が、いまの「基本的な考え方」と合っているか

なぜ大事か点数表の通知は、管理にあたって日本歯科医学会の「基本的な考え方」を参考にするよう示しています。口腔機能低下症は令和8年3月版、口腔機能発達不全症は令和6年3月版です。版が変わると、基準値や項目が変わります。低下症の令和8年3月版では、専用機器を使わない検査だけでも3項目以上の該当で診断できることが明記され、発達不全症の令和6年3月版では離乳完了後のチェックリストがC-1〜C-18の18項目になっています。古い版のままのアプリでは、該当項目の数え方が学会資料と食い違うことがあります。

確かめ方アプリの基準値や項目数を、学会資料と突き合わせます。見やすいのは、低下症の低舌圧の基準、発達不全症の別紙2の項目数です。あわせて、改定があったときにアプリがどう更新されるか（アップデートの履歴や告知）を見ておきます。基準値は「口腔機能低下症の7項目」と「発達不全症のチェックリスト」にまとめています。

3. 管理計画書・提供文書と、診療録への添付

CHECK 03文書を出せて、医院の診療録の運用に乗るか

なぜ大事か口腔機能管理料・小児口腔機能管理料の通知は、管理計画の情報を文書で提供し、その写しを診療録に添付すること、管理を行ったときは管理内容を診療録に記載するか、記録の文書（またはその写し）を添付することを求めています。歯科衛生士の口腔機能実地指導料も、指導内容を文書で提供し、その写しを診療録に添付します。発達不全症では、撮影したカラー写真を診療録に添付するか、電子媒体に保存して管理します。つまり、アプリで作った文書を印刷または保存して、紙カルテか電子カルテかという医院の運用に乗せられることが要になります。

確かめ方デモで管理計画書を1枚作り、印刷と保存を実際に行います。学会の「基本的な考え方」の別添にある管理計画書の項目（全身の状態、検査結果、管理計画、再評価の時期など）が入っているかを見ます。紹介状や実地指導の提供文書が必要な医院は、それも同じように試します。通知の要件は「低下症の算定」「発達不全症の算定」で確認できます。

4. 検査値の入力のしやすさ

CHECK 04チェアサイドで、無理なく入力できるか

なぜ大事か低下症の7項目には、専用機器で測る検査（舌圧、咬合力、咀嚼能力、口腔粘膜湿潤度、口腔細菌定量）と、機器を使わない検査（TCI、オーラルディアドコキネシス、EAT-10など）が混ざっています。機器の値は手で入力することが多く、1人あたりの入力時間が、運用が続くかどうかを左右します。入力する人が歯科医師か歯科衛生士かでも、使いやすさの基準は変わります。

確かめ方実際の検査の順番どおりに1人分を入力し、時間を測ります。タイマーやチャートなどの入力補助があるか、入力した値がすぐに基準値と並んで見えるかを確かめます。レセコンや電子カルテにも同じ内容を入力する運用になる場合は、二重入力の負担がどれだけ増えるか、連携があるならどのデータが受け渡されるかも見ます。入力を担当するスタッフ本人が試すことが大切です。

5. 再評価・写真撮影の時期を忘れない仕組み

CHECK 05時期が来た患者さんが、わかるか

なぜ大事か時期に関わる決まりは2種類あります。1つは学会の目安で、低下症の「基本的な考え方」では、概ね6か月ごとに精密検査で再評価し、そのたびに管理計画書を作成・交付するとしています。もう1つは通知の算定要件で、発達不全症では小児口腔機能管理料の初回算定日にカラー写真を撮影し、その後も管理料を3回算定するごとに1回以上撮影します。保険で算定する各精密検査は3月に1回に限られます。学会の目安は管理の質に、通知の要件は算定に関わるもので、どちらも、時期が来た患者さんを把握する手段がないと抜けやすくなります。

確かめ方前回の検査日や撮影日から期間がたった患者さんを、どう知らせるか（一覧に出るのか、通知が来るのか、自分で探すのか）を確かめます。写真を患者ごとに記録できるかも見ます。通知の方式は、アプリを開く頻度など医院の運用に合わせて選びます。

6. 複数端末・複数スタッフでの利用と料金

CHECK 06医院の台数で、いくらになるか

なぜ大事かチェアごと、担当者ごとに端末を使う医院では、端末数やスタッフ数で料金が変わる体系だと、総額が見積もりと違ってきます。同じ患者さんを複数の端末で開けるか、入力したデータが端末どうしでどう同期されるかも、日々の運用に関わります。スタッフごとにアカウントや権限を分けたいか、誰がいつ入力したかの操作履歴が要るかも、医院によって必要性が違います。iPhone・iPad・Androidが混在する医院は、対応端末も確かめます。

確かめ方医院で使う端末の台数と担当者の数を書き出し、その条件での総費用（台数・人数・年額）を計算します。スタッフごとの権限や操作履歴が必要な医院は、その機能の有無と、それが料金に含まれるかを確かめます。デモでは2台で同じ患者さんを開き、片方で入力した内容がもう片方に反映されるまでを見ます。

7. データの保存場所・バックアップ・解約後の持ち出し

CHECK 07患者データが、どこにあり、取り出せるか

なぜ大事か口腔機能の記録は患者情報です。端末内だけに保存されるのか、クラウドにも保存されるのか、保存先の事業者はどこか、バックアップはどう取るのかを、導入前に知っておく必要があります。解約した後に、それまでの記録を閲覧・印刷できるか、医院の手元に書き出せるか、サービスが終わるときはどうなるかも、長く使うほど重要になります。

確かめ方プライバシーポリシーで、保存場所と利用している事業者、アカウント削除の手順を読みます。無料期間中にデータの書き出しを実行し、書き出したファイルをパソコンで開いてみます。解約後の扱いは、FAQにあればそれを、なければ問い合わせて確かめます。

8. オフラインとネット環境

CHECK 08ネットが不安定な場所でも使えるか

なぜ大事か診療室の奥や訪問診療先では、Wi-Fiや電波が届かないことがあります。入力や文書の作成がネット接続を前提にしていると、その場で記録できません。

確かめ方端末を機内モードにして、検査の入力と管理計画書の作成・保存を試します。再接続したあとに、入力した内容が同期されるかも見ます。

9. 医療機器かどうか・診断は誰が行うか

CHECK 09アプリの役割を、正しく理解しているか

なぜ大事か検査結果の記録と書類作成を支援するアプリと、医療機器として位置づけられた製品とでは、役割が違います。記録・書類作成の支援であれば、アプリが行うのは、入力された値を基準値に照らして該当項目を集計することまでで、口腔機能低下症・口腔機能発達不全症の診断は歯科医師が行います。算定の可否も、各医院が通知と地域の審査の考え方で判断します。この前提を院内で共有しておかないと、「アプリが判定した」という理解になりかねません。

確かめ方提供元の表示で、医療機器かどうかを確かめます。画面や文書の表現が「該当項目の集計」「点数の目安」なのか、「診断」なのかを読みます。

10. 無料で試せる範囲とサポート

CHECK 10導入前に、運用に合うかを確かめられるか

なぜ大事かここまでの9項目は、使ってみないと確かめられないものがほとんどです。無料で試せるかどうか、試用やデモの条件（期間の長さ、期間中に使える機能の範囲、申し込みや担当者の立ち会いが要るか、終了後に自動で有料に移るか）、解約の手順、問い合わせ先と返答の早さが、確かめる手段になります。

確かめ方まず、無料で試せるのか、デモの申し込みが要るのかと、その条件を確かめます。無料期間のうちに、実際の患者さん1〜2人分で、検査の入力から管理計画書の作成、印刷または保存までを一連で行います。質問を1つ送って、返答を見ます。解約の手順も、期間が終わる前に確認しておきます。

口腔機能管理くんの場合

当社のアプリ「口腔機能管理くん」について、上の10項目に対する事実を表にします。確認元は、アプリ紹介ページ・サポート・プライバシーポリシーと、各ストアで配信中のバージョンの機能です（バージョンの配信状況はストアの表示によります）。

項目口腔機能管理くんの場合
1. 対応する範囲口腔機能低下症の7項目、口腔機能発達不全症のチェックリスト（離乳完了前の別紙1・離乳完了後の別紙2）、歯周検査（精密6点法・4点法・基本検査）、咬筋検査。周術期等口腔機能管理の書類作成には対応していません。
2. 学会の基準への追随低下症は、日本歯科医学会の基準値に照らして該当項目を集計します。発達不全症の離乳完了後のチェックリストは、バージョン1.9.6から令和6年3月版（18項目）に対応しています（2026年10月23日時点で Android 版は配信済み、iOS 版はストアの審査中。それまでの版は以前の17項目）。
3. 管理計画書・提供文書管理計画書、紹介状、口腔機能の実地指導で患者さんにお渡しする文書をPDFで作成できます。iOSの共有機能からAirPrintで印刷したり、メールやクラウドストレージに送信できます。診療録への添付は医院の運用で行います。
4. 検査値の入力機器の値は手入力です。TCIは9ゾーンの舌苔チャート、オーラルディアドコキネシスはタイマー内蔵（pa/ta/ka）、EAT-10・RSSTに対応しています。入力した結果はレーダーチャートで表示します。
5. 再評価・写真の時期前回の検査日から一定の期間がたった患者さんが、ホーム画面の「そろそろ再検査の時期です」に一覧で表示されます。経過写真を記録している患者さんは、前回の撮影から3か月たつとホーム画面の一覧に表示されます。プッシュ通知ではなく、アプリを開いたときに表示される仕組みです。写真の表示は撮影済みの患者さんの経過期間を知らせるもので、初回の撮影や算定回数にもとづく撮影の要件は別に確認してください。
6. 端末・スタッフと料金月額1,000円・年額9,800円（税込）。1つのアカウントで、医院のiPhone・iPad・Android端末を何台でも使え、同じアカウントでサインインすればデータは端末どうしで同期されます。台数で料金は変わりません。AppleとGoogleのアカウント間の移行は、エクスポート／インポートで行います。
7. 保存場所・持ち出しデータは端末内に保存され、サインインしている場合は当社が管理するクラウド（Google Cloud / Firebase）のアカウント別領域にも自動で保存されます。ホーム画面の「データ管理」から、JSONファイルへの書き出し（手元保管用）ができます。書き出したファイルは暗号化していない読める形式のテキストファイルで、患者情報・検査結果・スクリーニング・トレーニング記録などが含まれます（経過写真は含まれません）。解約後もデータの閲覧、書類のPDF出力・印刷、JSONエクスポートは引き続き使えます。アカウント削除（退会）はアプリ内から行えます。
8. オフライン検査・評価・PDF出力などの基本機能はオフラインで動作します。クラウドバックアップのみインターネット接続が必要です。
9. 医療機器か・診断記録と書類作成を支援するアプリで、医療機器ではありません。入力された検査結果を学会の基準値に照らして集計し、評価の結果に応じて関係する保険算定項目と点数の目安を表示します。診断は歯科医師が行い、算定の可否は各医院でご確認ください。レセコンとの連携には対応していません。
10. 無料で試せる範囲・サポートすべてのプランに1か月の無料トライアルがあります。無料期間の終了後は自動で有料プランに移行し、期間中に解約すれば料金はかかりません。解約後に制限されるのは、新しい患者さんの評価の保存（各モード5人目以降）です。患者説明動画は追加料金なしで使え、動画のQRコードを印刷できます。問い合わせはサポートページから。

2026年10月23日時点で配信中のバージョンの内容です。例外として、発達不全症の離乳完了後のチェックリスト18項目（バージョン1.9.6）は、同日時点で Android 版は配信済み、iOS 版はストアの審査中で、iOS で配信中の版は17項目です。機能や料金は変わることがあります。最新の情報はアプリ紹介ページとストアの説明でご確認ください。

口腔機能管理アプリの選び方についてよくある質問

口腔機能管理アプリは医療機器ですか？

製品によります。検査結果の記録と管理計画書などの書類作成を支援するアプリは、医療機器ではない位置づけのものがあります。その場合、診断は歯科医師が行い、アプリは入力された値を基準値に照らして該当項目を集計する役割にとどまります。導入前に、提供元の表示で医療機器かどうかと、画面の表示が「診断」ではなく「該当項目の集計」であることを確かめてください。

アプリで作った管理計画書は、そのまま管理料の要件を満たしますか？

書式だけでは決まりません。口腔機能管理料・小児口腔機能管理料の通知は、管理計画の情報を文書で提供し、その写しを診療録に添付すること、管理を行ったときは管理内容を診療録に記載するか記録の文書を添付することを求めています。日本歯科医学会の「基本的な考え方」には管理計画書の別添があります。アプリで作った文書に必要な項目が入っていること、印刷または保存して診療録に添付できることを、医院の運用で確かめてください。算定の可否は各医院の判断です。

無料期間やデモでは、何を試せばよいですか？

実際の患者さん1〜2人分で、検査値の入力から管理計画書の作成、印刷または保存までを一連で行ってみてください。入力にかかる時間、文書に必要な項目が入っているか、複数の端末で同じ患者を開けるか、機内モードで入力と出力ができるか、データを書き出して開けるか、問い合わせへの返答、の6つを見ると、医院の運用に合うかがわかります。

口腔機能低下症と口腔機能発達不全症の両方に対応している必要がありますか？

医院の患者層によります。口腔機能低下症は口腔機能管理料（7項目中3項目以上で診断）、口腔機能発達不全症は小児口腔機能管理料（18歳未満。診断基準は、「食べる機能」「話す機能」のC項目で2つ以上。離乳完了前はC-1〜C-9、離乳完了後はC-1〜C-6を1つ以上含むこと）と、対象も検査も違います。高齢の患者さんが中心なら低下症の7項目、小児が中心なら離乳完了前（別紙1）と離乳完了後（別紙2）のチェックリスト、両方を診るなら両方が必要です。周術期等口腔機能管理が必要な医院は、その書類に対応しているかも別に確かめてください。

レセコンと連携していないアプリは不便ですか？

医院の運用によります。検査結果の記録と書類作成をアプリで行い、算定の入力はレセコンで別に行う運用であれば、連携がなくても一連の流れは成り立ちます。連携を前提にしたい場合は、どのデータがどう受け渡されるかを導入前に確かめてください。
