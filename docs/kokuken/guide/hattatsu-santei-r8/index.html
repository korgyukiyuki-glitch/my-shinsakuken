GUIDE — 算定（口腔機能発達不全症）

口腔機能発達不全症の算定（令和8年度）──小児口腔機能管理料1・2、検査、指導・訓練の組み立て

監修：歯科医師 和泉龍之介（Medical Craft Lab） 公開日 2026年10月22日 最終更新日 2026年10月22日

令和8年度診療報酬改定（2026年6月施行）で、小児口腔機能管理料は1・2の2区分になり、評価項目が2項目の患者も算定の対象に加わりました。この記事では、告示・通知の原文と厚生労働省の改定概要をもとに、口腔機能発達不全症の点数・算定要件と、診断から継続管理までの算定の組み立てを整理します。

チェックリストのC項目と診断基準は、「口腔機能発達不全症のチェックリスト（離乳完了前・離乳完了後）とC項目の見方」で解説しています。

POINTS — この記事の要点

  • 小児口腔機能管理料1＝90点（評価項目3項目以上）、管理料2＝50点（評価項目2項目）。どちらも月1回
  • 区分は該当する項目の数で決まる。検査の実施で区分が決まる口腔機能低下症とは考え方が違う
  • 対象は口腔機能発達不全症と診断された18歳未満の患者。「口腔機能管理中」の患者は対象外
  • 小児口唇閉鎖力検査100点・舌圧検査140点は、それぞれ3月に1回。写真撮影は初回算定日と、管理料3回の算定に1回以上

小児口腔機能管理料の算定要件（1・2共通）

  • 歯科疾患管理料または歯科特定疾患療養管理料を算定した、口腔機能発達不全症の18歳未満の患者が対象（注1）
  • 関係学会の診断基準で口腔機能発達不全症と診断されている患者に、管理計画に基づいて継続的な管理を行う。管理には日本歯科医学会「口腔機能発達不全症に関する基本的な考え方」（令和6年3月）を参考にする（通知(1)）
  • 口腔機能の評価と一連の管理計画を策定して患者等に説明し、管理計画の情報を文書で提供して、写しを診療録に添付する。管理を行ったときは管理内容を診療録に記載するか、記録の文書（またはその写し）を添付する（通知(2)）
  • 口腔外または口腔内のカラー写真を撮影する（通知(3)。後述）
  • 口腔管理体制強化加算の届出をした診療所では、50点を加算（注5）
  • 情報通信機器を用いる場合（78点・44点）は、施設基準の届出が必要で、特に情報通信機器を用いた歯科診療を行うことが必要と認められる患者（過去に小児口腔機能管理料を算定した患者に限る）が対象。歯科オンライン指針に沿って行い、日本歯科医学会「歯科におけるオンライン診療に関する基本的な考え方」（令和6年3月）を参考にする（注7・通知(5)）
  • 入院中の患者への管理、退院した患者への退院日の属する月の管理の費用は、原則として入院料等に含まれる（医科歯科併設の医療機関で、歯科以外の病棟に入院中・退院した患者は例外）（注4）
  • 算定した月は、周術期等口腔機能管理料（Ⅰ）〜（Ⅳ）、回復期等口腔機能管理料、歯科疾患在宅療養管理料、小児在宅患者訪問口腔リハビリテーション指導管理料、歯科矯正管理料を算定できない（注6）

「評価項目」の数え方と、診断との関係

管理料1・2を分ける「口腔機能の評価項目」が具体的に何を指すかは、告示・通知には書かれていません。ここでは、診断基準との関係で確実にいえることと、運用上の整理を分けて説明します。

確実にいえること：診断基準を満たすことが前提

管理料の対象は「口腔機能発達不全症の18歳未満の患者」です（注1）。そのため、該当項目の数が2つ・3つあっても、診断基準を満たしていなければ管理料は算定できません。診断基準は、「食べる機能」「話す機能」のC項目で2つ以上、かつ離乳完了前はC-1〜C-9、離乳完了後はC-1〜C-6を1つ以上含むことです。

  • 例：離乳完了後で、C-9（構音の障害）とC-10（口唇の閉鎖不全）だけが該当 → 話す機能で2つだが、C-1〜C-6を含まないため診断基準を満たさず、管理料の対象外
  • 例：離乳完了後で、C-5（咀嚼時間）とC-10が該当 → 診断基準を満たし、該当は2項目なので管理料2

運用上の整理：「その他」の項目と検査欄の扱い

チェックリスト（別紙1・別紙2）には、診断の数に入らない「その他」の項目（体格、口呼吸、口蓋扁桃の肥大、いびき、低舌圧など）と、別紙2には口唇閉鎖力検査・舌圧検査の欄があります。これらを管理料1・2を分ける「評価項目」の数に含めるかどうかは、告示・通知・疑義解釈で明示されていません（2026年10月22日時点で確認できた範囲）。

チェックリストの該当項目すべて（「その他」を含む）を評価項目として数える読み方がありえますが、これは運用上の整理です。たとえば「C-5・C-10（診断基準を満たす）＋C-14（口呼吸）」の患者を3項目として管理料1とするかどうかは、地域の審査の考え方を確認してください。

写真撮影の要件

患者の成長発達に伴う口腔内等の状況変化の確認を目的として、患者の状態に応じて口腔外又は口腔内カラー写真撮影を行うこと。写真撮影は、当該管理料の初回算定日には必ず実施し、その後は少なくとも当該管理料を３回算定するに当たり１回以上行うものとし、診療録に添付又はデジタル撮影した画像を電子媒体に保存・管理する。
（令和8年 B000-4-2 小児口腔機能管理料 通知(3)）

管理料を毎月算定する場合、少なくとも3か月に1回は撮影することになります。「基本的な考え方」でも、初回時と少なくとも3か月ごとに顔貌・口腔周囲の写真を撮るとされています。撮影日と算定回数の対応がわかるように記録しておくと、確認がしやすくなります。

歯科疾患管理料との関係（90点）

小児口腔機能管理料は、歯科疾患管理料（または歯科特定疾患療養管理料）を算定した患者が対象です。歯科疾患管理料は令和8年度に90点になり、初診月の100分の80の規定はなくなりました。

  • 1回目は、患者等の同意を得て管理計画を作成し、その内容を説明した場合に算定（注1）
  • 口腔機能の回復もしくは維持・向上または獲得を目的とした管理を行う場合は、管理計画に、口腔機能の検査の結果を踏まえた治療方針を含める（通知(5)）

歯科口腔リハビリテーション料3（口腔機能の発達不全：50点）

歯科口腔リハビリテーション料3の「1 口腔機能の発達不全を有する18歳未満の患者の場合」（H001-4・50点）は、小児口腔機能管理料または歯科疾患在宅療養管理料を算定する患者に、口腔機能の獲得を目的として療養上必要な指導・訓練を行った場合に、月2回まで算定します（注1）。

  • 管理計画に基づいて口腔機能の指導・訓練を行い、「基本的な考え方」（令和6年3月）を参考にする（通知(1)）
  • 摂食機能療法を算定した日は算定できない（注3）
  • 指導・訓練内容などの要点を診療録に記載する（通知(5)）

口腔機能実地指導料（46点）の算定要件と施設基準

令和8年度に新設された口腔機能実地指導料（B001-2-2・46点）は、口腔機能発達不全症と口腔機能低下症の両方が対象です。「口腔機能の発達不全を有する患者に対して行う正常な口腔機能の獲得を目的とした実地指導」が、算定できる指導の1つに挙げられています（通知(1)ア）。

  • 研修を受けた歯科衛生士が、主治の歯科医師の指示を受けて口腔機能に関する指導を行い、指導内容を文書で提供した場合に、月1回。文書は初回のほか必要に応じて、少なくとも6月に1回以上提供する
  • 歯科口腔リハビリテーション料3を算定した日に、その指導・訓練と内容が重なる指導をした場合は算定できない
  • 施設基準の届出が必要（研修を受けた歯科衛生士の配置、指導の時間と歯科用ユニットの確保、歯科衛生士の処遇改善）。研修の要件は令和9年5月31日まで経過措置がある（令和8年度 疑義解釈その1 歯科 問8）
  • 発達不全症と低下症で異なる研修をそれぞれ受講した場合も該当し、届出では受講したそれぞれの研修を様式17の4に記載する（令和8年度 疑義解釈その2 問5）

文書の記載事項や経過措置中の届出の書き方は、「口腔機能低下症の算定（令和8年度）」の同じ節で詳しく解説しています。

口腔機能発達不全症の算定の組み立て：診断から継続管理まで

  1. 診断の前：傷病名「口腔機能発達不全症の疑い」で、チェックリストによる評価と、診断を目的とした小児口唇閉鎖力検査・舌圧検査を行う。
  2. 診断：食べる・話すのC項目で2つ以上（必須の項目を1つ含む）に該当すれば口腔機能発達不全症。管理計画を作成して患者等の同意を得て、文書で提供する。歯科疾患管理料の管理計画にも、口腔機能の検査結果を踏まえた方針を含める。
  3. 初回の算定：歯科疾患管理料と、小児口腔機能管理料1または2（評価項目の数で区分）。初回算定日には写真撮影が必須。
  4. 指導・訓練：歯科口腔リハビリテーション料3（1）を月2回まで。施設基準を届け出た医院は、口腔機能実地指導料（月1回）。同じ日に内容が重なる場合、実地指導料は算定できない。
  5. 検査：小児口唇閉鎖力検査・舌圧検査は、それぞれ3月に1回まで。
  6. 写真：管理料3回の算定に1回以上。「基本的な考え方」では少なくとも3か月ごと。
  7. 再評価：指導・訓練の評価を続け、必要に応じて管理計画を再立案する。改善すれば管理終了（治癒）、改善が乏しい場合は再立案または中止。

チェックリストで該当はあるものの診断基準に届かず「口腔機能管理中」とした患者は、小児口腔機能管理料の対象になりません（注1）。歯科口腔リハビリテーション料3（1）も、小児口腔機能管理料または歯科疾患在宅療養管理料を算定する患者が対象です。傷病名の整理は「傷病名の3段階」をご覧ください。

小児口腔機能管理料の算定についてよくある質問

小児口腔機能管理料1と2の違いは何ですか？

管理料1（90点）は口腔機能の評価項目で3項目以上に該当する患者、管理料2（50点）は2項目に該当する患者が対象です。どちらも、歯科疾患管理料または歯科特定疾患療養管理料を算定した、18歳未満の口腔機能発達不全症の患者に、管理計画に基づいて管理を行った場合に月1回に限り算定します（告示 B000-4-2 注1〜3）。

チェックリストで2項目該当すれば、小児口腔機能管理料2を算定できますか？

管理料は口腔機能発達不全症の患者が対象なので、まず診断基準を満たしていることが前提です。診断基準は「食べる機能」「話す機能」のC項目で2つ以上、かつ離乳完了前はC-1〜C-9、離乳完了後はC-1〜C-6を1つ以上含むことです。この条件を満たさない2項目（例：話す機能だけで2項目）では、口腔機能発達不全症の診断に至らないため、管理料の対象になりません。

小児口唇閉鎖力検査と舌圧検査に施設基準の届出は必要ですか？

令和8年度の告示（D011-4、D012）の注と通知には、施設基準に関する定めはありません。いずれも3月に1回に限り算定します。点数は小児口唇閉鎖力検査が100点、舌圧検査が140点です。

「口腔機能管理中」の患者に小児口腔機能管理料は算定できますか？

できません。小児口腔機能管理料は口腔機能発達不全症の18歳未満の患者が対象です（告示 B000-4-2 注1）。確定診断に至らず「口腔機能管理中」とした患者は対象になりません。

写真撮影はいつ必要ですか？

小児口腔機能管理料の初回算定日には必ず撮影し、その後は少なくとも管理料を3回算定するごとに1回以上撮影します。患者の状態に応じて口腔外または口腔内のカラー写真を撮り、診療録に添付するか、デジタル撮影した画像を電子媒体に保存・管理します（B000-4-2 通知(3)）。

口腔機能低下症の管理料と、区分の考え方は同じですか？

違います。口腔機能管理料（低下症）は、指定の5つの検査のいずれかを実施したかどうかで1・2を分けます。小児口腔機能管理料は、口腔機能の評価項目に該当する数（3項目以上か2項目か）で1・2を分けます。

口腔機能実地指導料の研修は、発達不全症と低下症で別々に受けてもよいですか？

差し支えありません。口腔機能発達不全症と口腔機能低下症で異なる研修をそれぞれ受講した場合も施設基準の研修に該当し、届出の際は様式17の4に受講したそれぞれの研修を記載します（令和8年度 疑義解釈その2 問5）。

算定の目安と写真の時期をアプリで確認する

「口腔機能管理くん」は、歯科医院向けの口腔機能管理アプリです。チェックリストの該当項目を記録すると、項目数を集計し、評価の結果に応じて関係する保険算定項目と点数の目安をアプリ内に表示します。経過写真を記録している患者さんは、前回の撮影から3か月たつとホーム画面の一覧に表示され、管理計画書はPDFで作成できます。写真の表示は撮影済みの患者さんの経過期間を知らせるもので、初回の撮影や算定回数にもとづく撮影の要件は別に確認してください。
