GUIDE — 記録の続け方

JSG EXAM7 の廃止後に確かめること──口腔機能低下症の記録と管理計画書を続けるために

執筆・監修：歯科医師 和泉龍之介（Medical Craft Lab） 公開日 2026年11月25日 最終更新日 2026年11月25日

日本老年歯科医学会の口腔機能低下症の記録アプリ「JSG EXAM7」は、2026年3月31日をもって廃止されました。学会のお知らせ（2025年7月17日更新）によると、廃止は2025年3月27日の理事会で正式に決まり、新規の利用開始はすでに停止されていました。

2026年3月31日の利用停止とともにデータはすべて消去され、停止後にデータを取り出すことはできない、とされています。

この記事は、JSG EXAM7 で行っていた口腔機能低下症の検査記録と管理計画書の作成を、廃止後も続けるために、医院で確かめたいことを整理したものです。学会のお知らせには、廃止後に利用する製品の案内はありません（2026年11月25日に確認）。

特定の製品を勧める記事ではなく、記録の方法を選ぶときの確認点をまとめています。最後に、この記事を書いた歯科医師が開発しているアプリ「口腔機能管理くん」が、確認点にどう当てはまるかを、事実だけ載せます。

POINTS — この記事の要点

  • JSG EXAM7 は2026年3月31日に廃止され、データは消去済み。学会のお知らせでは、停止後の取り出しはできないとされている
  • まず、廃止前に印刷・保存した管理計画書や記録が、診療録として残っているかを患者ごとに確かめる
  • 続ける方法は、紙の記録用紙・電子カルテやレセコンの機能・口腔機能管理のアプリの3つ。どれでも、今の学会の基準に合うことと、管理計画書を文書で出して写しを診療録に添付できることが要
  • 新しい方法を選ぶときは、データの保存場所・書き出し・サービスが終わるときの扱いも確かめる

学会のお知らせの要点

日本老年歯科医学会は、会員向けのお知らせ「【重要】JSG EXAM7について廃止のお知らせ」で、次のことを示しています（要約。原文は学会のページで確認できます）。

決定2025年3月27日の理事会で、2026年3月31日をもって廃止することが正式に決定
新規の利用新規の利用開始は、すでに停止
データ2026年3月31日の利用停止で、すべて消去。停止後は、データの取り出しは一切できない
経緯（2025年1月20日のお知らせ）2018年に学会主導の臨床研究のために開発。当時の検査を対象としており、新しい検査や現在の口腔機能管理への対応に限界があり、更新の予定もないことなどから、2024年12月20日の理事会で廃止に向けた議論を始めた

1. 廃止前の記録が、診療録として残っているか

口腔機能管理料の通知は、管理計画の情報を文書で提供し、その写しを診療録に添付すること、管理を行ったときは管理内容を診療録に記載するか、記録の文書を添付することを求めています。JSG EXAM7 で作った管理計画書や記録を、印刷やPDFで診療録に残していれば、それが医院の記録です。

最初に、管理中の患者さんごとに、何が残っているか（最後の検査日、各項目の値、管理計画書の写し）を確かめます。学会のお知らせのとおり、廃止後にアプリのデータを取り出すことはできません。

残っていない分は、診療録の記載から、前回の検査日と経過を確かめることになります。

2. 記録を続ける3つの方法

廃止後の記録は、大きく3つの方法で続けられます。どれが正解ということはなく、患者数と、すでに使っている仕組みで選びます。

方法向いている医院確かめること
紙の記録用紙管理する患者さんが少ない。すぐに始めたい今の学会の資料に合う様式か。前回の結果との比較と、再評価の時期の管理は医院で行う。
記録用紙の使い方は「記録用紙」の記事にまとめています
電子カルテ・レセコンの機能使っている製品に、口腔機能の記録の機能がある7項目の入力と管理計画書の出力に対応しているか。学会の基準が改訂されたときに、どう更新されるか
口腔機能管理のアプリチェアサイドで入力し、管理計画書までを1つで作りたい下の5つのこと。導入前の確認点は「口腔機能管理アプリの選び方」で10項目に整理しています

3. 方法を選ぶときに確かめる5つのこと

CHECK 01今の学会の基準に合っているか

点数表の通知は、管理にあたって日本歯科医学会の「基本的な考え方」を参考にするよう示しています。口腔機能低下症は令和8年3月版が最新です。

学会のお知らせでも、JSG EXAM7 が当時の検査を対象にしていて、新しい検査や現在の口腔機能管理に十分対応できないことが、廃止の経緯として挙げられています。新しい方法では、基準値と項目が今の版と合っているかを、学会資料と突き合わせて確かめます。

7項目と基準値は「口腔機能低下症とは」にまとめています。

CHECK 02管理計画書を文書で出し、写しを診療録に添付できるか

管理計画の情報の文書提供と、写しの診療録への添付は、管理料の通知が求めていることです。印刷できるか、PDFで保存できるか、紙カルテ・電子カルテという医院の運用に乗るかを、1人分を作って確かめます。

要件は「口腔機能低下症の算定」で確認できます。

CHECK 03再評価の時期をつかめるか

学会の「基本的な考え方」は、概ね6か月ごとに精密検査で再評価し、そのたびに管理計画書を作成・交付するとしています。保険で算定する各精密検査は、3月に1回に限られます。

時期が来た患者さんを、一覧や通知で知らせる仕組みがあるか、医院で管理するかを決めておきます。

CHECK 04前回の結果と比べられるか

口腔機能の管理は、前回からの変化を見て計画を立て直す流れです。JSG EXAM7 の記録は、新しい方法に自動で移らないものとして考え、印刷やPDFで残した前回の結果を手元に置いて、新しい方法での最初の評価のときに参照します。

2回目からは、新しい方法の中で前回と比べられるかを確かめます。

CHECK 05データの保存場所・書き出し・終わるときの扱い

JSG EXAM7 の廃止は、記録の道具にも終わりがあることを示しました。新しい方法を選ぶときは、データがどこに保存されるか（端末内か、クラウドか）、医院の手元に書き出せるか、解約したあとや、サービスが終わるときにどう知らされ、どれだけの期間で取り出せるかを、プライバシーポリシーや利用規約、問い合わせで確かめます。

書き出しは、導入してすぐに一度試しておくと安心です。

口腔機能管理くんの場合

当社のアプリ「口腔機能管理くん」について、上の5つのことに対する事実を表にします。口腔機能管理くんには、JSG EXAM7 のデータを読み込む機能はありません。

また、日本老年歯科医学会との提携や、学会による推奨はありません。確認元は、アプリ紹介ページ・サポート・プライバシーポリシーと、各ストアで配信中のバージョンの機能です。

項目口腔機能管理くんの場合
1. 学会の基準口腔機能低下症の7項目の検査結果を入力すると、日本歯科医学会の基準値に照らして該当項目を集計し、レーダーチャートで表示します。診断は歯科医師が行います。
2. 管理計画書管理計画書、紹介状、口腔機能の実地指導で患者さんにお渡しする文書をPDFで作成できます。印刷や、メール・クラウドストレージへの送信ができます。
診療録への添付は医院の運用で行います。
3. 再評価の時期前回の検査日から一定の期間がたった患者さんが、ホーム画面の「そろそろ再検査の時期です」に一覧で表示されます。プッシュ通知ではなく、アプリを開いたときに表示される仕組みです。
4. 前回との比較保存した評価は経過グラフに並び、前回の結果と比べられます。JSG EXAM7 の記録は読み込めないため、最初の評価は、保存した前回の記録を見ながら行ってください。
5. 保存場所・書き出しデータは端末内に保存され、サインインしている場合は当社が管理するクラウド（Google Cloud / Firebase）のアカウント別領域にも自動で保存されます。ホーム画面の「データ管理」から、JSONファイルへの書き出し（手元保管用）ができます。
解約後もデータの閲覧、書類のPDF出力・印刷、書き出しは引き続き使えます。
料金月額1,000円・年額9,800円（税込）。検査の種類ごとに、評価を保存した患者4人までは無料で使えます（患者登録は無制限）。
すべてのプランに1か月の無料トライアルがあります。医院の端末は何台でも使えます。

JSG EXAM7 の廃止後の記録についてよくある質問

JSG EXAM7 は今も使えますか？

使えません。日本老年歯科医学会のお知らせによると、JSG EXAM7 は2026年3月31日をもって廃止され、利用停止とともにデータはすべて消去されました。

停止後にデータを取り出すことはできない、とされています。

JSG EXAM7 の代わりとして、学会が勧めるアプリはありますか？

学会のお知らせには、廃止後に利用する製品の案内はありません（2026年11月25日に確認）。廃止後の記録の方法は、各医院で選ぶことになります。

廃止前に保存した JSG EXAM7 の記録は、どう参照すればよいですか？

廃止後は、学会からデータを取り出すことはできません。廃止前に印刷やPDFで保存した記録は、医院の記録として保管し、新しい方法での最初の評価のときに前回の検査値として参照してください。

口腔機能管理くんには、JSG EXAM7 のデータを読み込む機能はありません。

アプリを使わず、紙の記録用紙で続けてもよいですか？

構いません。口腔機能管理料の通知が求めているのは、管理計画の情報を文書で提供し、その写しを診療録に添付することなどで、記録に使う道具は指定していません。

紙で続ける場合は、前回の結果との比較と、再評価の時期の管理を医院で行います。
