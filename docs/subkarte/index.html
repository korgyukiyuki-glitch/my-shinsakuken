HOW IT WORKS

診療の流れに、そのまま乗る。

紙のサブカルテを探す時間、見積書を後から作り直す時間をなくします。

1

患者を選ぶ

患者を登録・選択します。カルテメモも治療計画も見積書も、同じ患者にひもづきます。

2

カルテメモに書く

日付・本日の処置・次回の処置が並んだ用紙に、ペンでそのまま書き込みます。

3

治療計画を立てる

歯式の図で歯を選び、予定を登録。来院ごとに「今日の記録」をつけて進み具合を残します。

4

自費を提案する

歯を選んで見積書を作成。同意書の署名から成約の記録まで、その場で完結します。

FEATURES

書く・計画する・提案する、を1つに。

サブカルテと自費の提案を別々のツールに分けず、同じ患者の記録としてつなげます。

✍️

手書きのカルテメモ

紙のサブカルテと同じ帳票に、ペンでそのまま書き込めます。

  • ペン・マーカー・消しゴム・文字入力
  • 行ごとに日付と担当者を記録
  • 拡大して細かく書ける・用紙は何枚でも追加
🗓️

歯式で見る治療計画

どの歯に何を予定していて、どこまで終わったかが図でわかります。

  • 歯を選んで予定を登録
  • 来院ごとに「今日の記録」を残す
  • 予定と完了を色分けして表示
🦷

歯式ベースの見積書

どの歯にどの治療をするかを図で示せるので、患者様に伝わります。

  • 料金マスタから選ぶだけ
  • ブリッジは支台・ポンティック別単価に対応
  • 税込／税抜・値引き行にも対応
📄

複数案の提示

1つの見積の中に松・竹・梅のような複数案を用意し、患者様に選んでいただけます。

  • 案ごとに明細・金額を作成
  • PDFで比較しながら説明
🖊️

同意書と電子サイン

抜歯・インプラント・矯正など、よく使う同意書をテンプレートから作成できます。

  • 医院名・患者名は自動で差し込み
  • その場で署名しPDFに記録
  • 紙で運用する場合は署名欄を空欄で印刷
📋

成約管理

提示した見積が「検討中」のまま忘れられるのを防ぎます。

  • 提示済み／検討中／成約／見送り
  • 未確定リストで終業前に一括入力
  • 担当者を記録できる
📊

実績の集計

件数・金額・成約率を集計し、医院の自費の動きを数字で確認できます。

  • 治療別・担当者別の集計
  • 期間で絞り込み・前月比
🎬

患者説明動画

治療内容の説明に使える動画を収録。待ち時間や説明時にご活用いただけます。

  • 追加料金なしでご利用可能

THE POINT

探さない。忘れない。

サブカルテを探す時間も、提案したまま忘れてしまう見積も、記録が1か所にあれば減らせます。

「前回、どこまで
やったっけ？」をなくす。

前回の処置と次回の予定は、患者を開けばカルテメモと治療計画に残っています。 提示した見積は未確定リストに残り、終業前の数分でまとめて片付けられます。

  • 前回の処置・次回の予定がすぐ開ける
  • 提示した見積が一覧に残る
  • タップだけでステータスを更新
  • 担当者ごとの成約率がわかる
  • 治療別に「何が決まりやすいか」が見える
  • 受付・トリートメントコーディネーターでも扱える画面

SECURITY

患者情報を扱うアプリとして。

医療機関でお使いいただくことを前提に設計しています。

🔒

PINロック

アプリ起動時にPIN認証。PINは端末のセキュア領域（キーチェーン）に保存されます。

🔐

通信の暗号化とアクセス制御

端末とサーバー間の通信はTLSで暗号化。データはアカウント単位のアクセス制御で保護され、他のユーザーが閲覧することはできません。

🗑️

削除できる

アプリ内からデータの個別削除と退会ができます。退会時は署名済みPDFを含めて削除されます。

詳細はプライバシーポリシーをご確認ください。
