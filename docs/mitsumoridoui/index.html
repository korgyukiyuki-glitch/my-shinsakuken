HOW IT WORKS

チェアサイドで完結する4ステップ。

紙の見積書を後から作り直したり、同意書を探して印刷したりする時間をなくします。

1

患者を選ぶ

患者を登録・選択します。既に登録済みの患者はそのまま呼び出せます。

2

歯を選んで見積

料金マスタから治療を選び、対象の歯をタップ。金額と歯式入りの見積書ができます。

3

同意書に署名

治療に応じた同意書を呼び出し、画面上で患者様にサインいただきます。

4

結果を記録

提示・検討中・成約・見送りを記録。終業前にまとめて入力もできます。

FEATURES

提案の「作る」と「追う」を、両方。

書類作成だけで終わらせず、提案したあとどうなったかまで残せます。

🦷

歯式ベースの見積書

どの歯にどの治療をするかを図で示せるので、患者様に伝わります。

  • 料金マスタから選ぶだけ
  • ブリッジは支台・ポンティック別単価に対応
  • 税込／税抜・値引き行にも対応
📄

複数案の提示

1つの見積の中に松・竹・梅のような複数案を用意し、患者様に選んでいただけます。

  • 案ごとに明細・金額を作成
  • PDFで比較しながら説明
🖊️

同意書と電子サイン

抜歯・インプラント・矯正など、よく使う同意書をテンプレートから作成できます。

  • 医院名・患者名は自動で差し込み
  • その場で署名しPDFに記録
  • 紙で運用する場合は署名欄を空欄で印刷
📋

成約管理

提示した見積が「検討中」のまま忘れられるのを防ぎます。

  • 提示済み／検討中／成約／見送り
  • 未確定リストで終業前に一括入力
  • 担当者を記録できる
📊

実績の集計

件数・金額・成約率を集計し、医院の自費の動きを数字で確認できます。

  • 治療別・担当者別の集計
  • 期間で絞り込み・前月比
🎬

患者説明動画

治療内容の説明に使える動画を収録。待ち時間や説明時にご活用いただけます。

  • 追加料金なしでご利用可能

THE POINT

提案したあとを、忘れない。

自費が決まらない一番の理由は、提案の質より「そのあと」が追えていないことかもしれません。

「あの患者さん、
どうなったっけ？」をなくす。

見積を出したまま結果が記録されていないと、次のアプローチもできません。 本アプリは提示した見積を未確定リストに残し、終業前の数分でまとめて片付けられるようにしました。

  • 提示した見積が一覧に残る
  • タップだけでステータスを更新
  • 担当者ごとの成約率がわかる
  • 治療別に「何が決まりやすいか」が見える
  • 受付・トリートメントコーディネーターでも扱える画面

SECURITY

患者情報を扱うアプリとして。

医療機関でお使いいただくことを前提に設計しています。

🔒

PINロック

アプリ起動時にPIN認証。PINは端末のセキュア領域（キーチェーン）に保存されます。

🔐

通信の暗号化とアクセス制御

端末とサーバー間の通信はTLSで暗号化。データはアカウント単位のアクセス制御で保護され、他のユーザーが閲覧することはできません。

🗑️

削除できる

アプリ内からデータの個別削除と退会ができます。退会時は署名済みPDFを含めて削除されます。

詳細はプライバシーポリシーをご確認ください。
