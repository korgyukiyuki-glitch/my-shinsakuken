プライバシーポリシー

Medical Craft Laboratory（以下「当方」）は、歯科見積もり同意書くん（以下「本アプリ」）をご利用いただくユーザーのプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

本アプリは歯科医療機関の業務用アプリです。本アプリに患者情報を入力される歯科医院の皆様は、当該情報の管理者として、個人情報保護法および医療・介護関係事業者における個人情報の適切な取扱いのためのガイダンスに基づく責務を負います。本ポリシーは、当方が提供するアプリおよびサーバー側での取り扱いを説明するものです。

1. 収集する情報

本アプリでは、ユーザー（歯科医院）が業務のために以下の情報を入力・保存します。

  • 患者の基本情報（氏名、生年月日、性別、患者ID など）
  • 自費診療の見積書の内容（治療項目、部位、金額、有効期限など）
  • 同意書・承諾書の内容および作成日時
  • 電子署名（患者ご本人・保護者の手書きサイン画像）を含むPDF文書
  • 成約状況（提示・検討中・成約・見送り）、担当者名などの業務管理情報
  • アプリの設定情報（自費診療の料金マスタ、医院情報、PINコード等）

本アプリは、広告の表示や第三者の行動分析ツールを使用しません。ユーザーの操作履歴を広告目的で収集・追跡することはありません。

2. 認証について

本アプリのご利用には、Appleでサインイン または Googleアカウントによるサインインが必要です。当方が取得するのは、アカウントを識別するためのユーザーIDおよびメールアドレスです。パスワードを当方が取得・保管することはありません。

「Appleでサインイン」において「メールを非公開」を選択された場合、当方にはAppleが発行する転送用アドレスのみが提供されます。

3. データの保存場所

入力されたデータは、ご利用の端末内に保存されるとともに、同一アカウントの複数端末で利用できるよう、当方が管理するクラウド（Google Cloud / Firebase）上のアカウント別領域に保存されます。

  • Firestore（データベース）: 患者情報、見積書、同意書などの記録
  • Cloud Storage: 署名済みPDFなどの生成文書

これらはアカウント（ユーザーID）ごとに区分された領域に保存され、アクセス制御ルールにより、他のユーザーが別のユーザーのデータを読み書きすることはできません。

4. セキュリティ

本アプリは以下のセキュリティ対策を実施しています。

  • 端末とサーバー間の通信は、すべてTLSにより暗号化されます
  • サーバー上のデータは、アカウント単位のアクセス制御ルールにより保護され、認証された本人のみが読み書きできます
  • 保存データは、クラウド事業者（Google Cloud）により保存時暗号化が行われます
  • PINコードによるアプリロック。PINは端末のセキュア領域（iOS キーチェーン）に保存されます
  • 端末内の一時データ・復旧用バックアップは、端末のセキュア領域に保管された鍵で難読化して保存されます

4-1. 当方によるデータの閲覧について

透明性のためにご説明します。サーバー上のデータは当方の管理下にあり、技術的には当方が内容を閲覧することが可能な状態です（エンドツーエンド暗号化は行っておりません）。当方は、以下の場合を除き、お客様のデータの内容を閲覧いたしません。

  • お客様からのお問い合わせ対応・障害調査のため、お客様の同意を得て確認する場合
  • システム障害からの復旧など、サービス提供上やむを得ない場合
  • 法令に基づく開示請求があった場合

5. 第三者への提供

当方は、ユーザーおよび患者の個人情報を第三者に提供、販売、貸与することはありません。ただし、法令に基づく開示請求があった場合はこの限りではありません。

本アプリは、サービス提供のために以下の外部サービスを利用しています。

  • Google Firebase（Google LLC）: 認証、データベース、ファイル保存
  • RevenueCat（RevenueCat, Inc.）: サブスクリプションの購入状態の管理。購入情報および匿名のアカウント識別子を扱います
  • Apple: App Store を通じた課金処理

6. データ・アカウントの削除

6-1. アプリ内からの削除

アプリ内の「データ管理」画面から、患者データ・見積書・同意書などを個別に削除できます。また、アプリ内からアカウントの削除（退会）を行うことができ、この場合はクラウド上のデータおよび署名済みPDFを含めて削除されます。

6-2. メールによる削除リクエスト

アプリを利用できない状況などでアカウントおよびデータの完全削除をご希望の場合は、以下の手順でリクエストしてください。

  1. medicalcraft.lab@gmail.com 宛にメールで削除リクエストをお送りください。
  2. メール件名に「歯科見積もり同意書くん アカウント削除リクエスト」と明記してください。
  3. 本文には、本アプリへのサインインに使用したメールアドレスを記載してください。

6-3. 削除されるデータの種類

  • Firebase Authentication 上のアカウント情報（メールアドレス、ユーザーID）
  • クラウドに保存された患者情報、見積書、同意書、成約状況などのデータ
  • Cloud Storage に保存された署名済みPDFを含むすべての生成文書

6-4. 保持期間

削除リクエストを受領後、30日以内にすべての関連データを当方のシステムから完全に削除します。法令により保持が義務付けられている場合を除き、削除後にデータが復元されることはありません。サブスクリプション契約中の場合は、App Store 上での解約手続きが別途必要です。

7. お子様のプライバシー

本アプリは歯科医療従事者が業務で使用することを想定しています。13歳未満のお子様が直接使用することは想定しておらず、お子様から意図的に個人情報を収集することはありません。なお、患者情報として未成年の方の氏名等をユーザーが入力する場合がありますが、その管理責任はユーザーである歯科医院にあります。

8. ポリシーの変更

本ポリシーは、必要に応じて改定することがあります。重要な変更がある場合は、アプリ内またはこのページにてお知らせします。
