使い方

見積書はどうやって作りますか？

ホーム画面の「見積書」から作成します。患者を選び、あらかじめ登録した料金マスタから治療項目を選ぶだけで明細ができます。歯式（歯の番号）を指定すれば、どの歯にどの治療を行うかを図で示した見積書になります。

1つの見積の中に複数の案（松・竹・梅など）を作成でき、患者様に選んでいただけます。

料金マスタはどこで登録しますか？

「料金マスタ」画面から、医院ごとの自費診療メニューと金額を登録できます。カテゴリごとに整理でき、税込・税抜の指定も可能です。ブリッジは支台とポンティックで単価を分けて登録することもできます。

同意書・承諾書にはどんな種類がありますか？

抜歯、インプラント、矯正、ホワイトニング、マイクロスコープ根管治療、ボツリヌス治療、自費診療の見積承諾書などのテンプレートを収録しています。医院名や患者名は自動で差し込まれ、特記事項を自由に追記できます。

抜歯同意書は保険診療でも使用されるため、ホーム画面から直接アクセスできます。

電子サインはどう使いますか？

同意書・承諾書のプレビュー画面から署名パッドを開き、患者様ご本人（未成年の場合は保護者）に画面上でサインしていただきます。署名するとPDFに焼き込まれ、以後は内容が変更できない記録として保存されます。作成したPDFは共有・印刷できます。

紙の運用を続けたい場合は、署名欄を空欄にしたPDFを印刷してご利用いただけます。

提示した見積のその後を管理できますか？

はい。各見積に「提示済み・検討中・成約・見送り」のステータスを設定できます。ホーム画面の未確定リストから、その日提示した分をまとめて入力できるため、終業前の数分で整理できます。

「実績」画面では、件数・金額・成約率を治療別／担当者別／期間別に集計して確認できます。

アカウント・データ

複数のデバイスでデータを共有できますか？

はい。同じアカウントでサインインすれば、iPhone と iPad など複数の端末で同じデータをご利用いただけます。

なお、同じアカウントで同時に複数端末から編集した場合、後から保存した内容が反映されます。

PINコードを忘れてしまいました

サインイン画面から一度サインアウトし、同じアカウントで再度サインインするとPINを再設定できます。クラウドに保存されたデータは失われません。

患者データの安全性について教えてください

端末とサーバー間の通信はすべてTLSで暗号化されます。サーバー上のデータはアカウント単位のアクセス制御で保護され、他のユーザーが別のユーザーのデータを閲覧することはできません。アプリはPINコードでロックできます。

データの取り扱いの詳細はプライバシーポリシーをご確認ください。

データを削除したい／退会したい

アプリ内の「データ管理」からデータの個別削除、およびアカウントの削除（退会）ができます。退会するとクラウド上のデータと署名済みPDFも削除されます。

アプリを利用できない状況の場合は、下記のメールアドレスまでご連絡ください。

無料で使える範囲はありますか？

ご契約前でも、見積書を3件まで作成してお試しいただけます（作成済みの見積の編集は件数に含まれません）。

同意書・承諾書の作成と電子サインは、有料期間の開始後にご利用いただけます。書類として保存される性質上、1か月の無料期間中はご利用いただけませんのでご了承ください。

なお、一度作成した書類の閲覧・PDFの共有・印刷・削除は、期間や契約状態にかかわらずいつでも行えます。

解約したい／課金が反映されない

解約は iPhone / iPad の「設定」→（お名前）→「サブスクリプション」から行えます。

ご購入手続きが完了しているのに機能が解放されない場合は、アプリ内の「購入を復元」をお試しください。それでも解決しない場合は、お手数ですが下記までご連絡ください。
