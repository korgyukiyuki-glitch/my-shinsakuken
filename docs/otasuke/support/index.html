サポート

よくある質問と、お問い合わせ先をご案内します。

PIN を忘れてしまいました

PIN の画面の「PINを忘れた場合」から、医院のアカウントでサインインし直して、新しい PIN を2回入れてください。予定のデータは消えません。PIN は同じ開発者の「口腔機能管理くん」「歯科サブカルテ&コンサルくん」と共通です。

2台以上の iPad・iPhone で使えますか？

はい。同じ医院のアカウントでサインインすると、予定はクラウドを通して端末どうしで同期されます。同じ予定を2台で同時に直したときは、どちらの内容も消さずに残し、あとで選べます。

データのバックアップは？

同期を使っている間は、予定がクラウドにも保存されます。加えて「設定」の「バックアップを保存」で、バックアップファイルを手元に保存できます（パスワードを決めると暗号化して保存します）。端末の故障や機種変更に備えて、ときどき保存してください。

オフラインでも使えますか？

はい。その端末で医院の周りの道路データを一度取り込んだあとは、予定の確認・入力・順番の計算は端末の中で動きます（別の端末で初めて使う時、医院の位置や訪問範囲を変えた時、道路データを最新にする時は通信します）。電波のない間に入れた予定は「送信待ち」として残り、つながったときにクラウドへ送られます。

順番の計算に、患者さんの位置を外部に送りますか？

道のりの計算は端末の中で行い、経路検索のサービスには送りません。住所から位置を探すときと地図を表示するときは国土地理院の住所検索・地図を使い（設定で止められます）、道案内のときは Google マップを開くため、行き先が Google に渡ります。道路のデータは、医院の周りの分だけを配信元（Cloudflare）から取り込みます。このとき医院のおおよその位置と端末の IP アドレスが配信元に伝わります（患者さんの位置は送りません）。

到着時刻が実際と違います

到着時刻は、道路の距離と設定の速さから出す目安です。渋滞などの交通状況は反映しません。設定の「平均の移動速度」「1件の所要時間」や、予約ごとの治療時間を、医院の実際に合わせて直してください。

「道路データの範囲外」と出て、距離が計算できません

道路のデータは日本全国で使えますが、端末に取り込むのは医院の周りだけです（標準の設定で約25km・設定の「訪問範囲」に応じて約25〜60km。範囲を広げると、その分を取り込みます）。そこから外れた訪問先や、道路のない所に置かれた位置は、道順の計算に入りません。患者さんの位置を地図で確かめてください。また、フェリーの区間は道路として扱わないため、フェリーをはさむ移動は計算できません（島の中の移動は計算できます）。

算定の判断はしてくれますか？

いいえ。歯周検査（P検査）から1か月の印などは日付からの目安です。点数・算定の判断は医院で行ってください。本アプリは医療機器ではありません。
